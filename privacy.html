Политика конфиденциальности

Content Factory — внутреннее приложение для публикации видео на YouTube-каналах, принадлежащих владельцу приложения. Приложение используется только владельцем и не предназначено для сторонних пользователей.

Какие данные используются

Приложение запрашивает доступ к YouTube Data API и YouTube Analytics API (загрузка видео, управление собственными видео, чтение статистики своих каналов). Токены доступа хранятся локально на оборудовании владельца и не передаются третьим лицам.

Что не делается

Приложение не собирает, не хранит и не передаёт персональные данные зрителей или других пользователей Google. Данные используются исключительно для публикации контента и анализа статистики собственных каналов.
